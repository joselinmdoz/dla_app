# DLA Viajes y Envios

Sitio web y panel administrativo de `DLA Viajes y Envíos`, construido con `Next.js`, `React`, `TypeScript` y `Tailwind CSS`.

## Objetivo

Este repositorio contiene la web pública y las herramientas internas para la gestión de contenido, productos, clientes, envíos y configuración del sitio.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

También puedes usar `npm` si prefieres:

```bash
npm install
npm run dev
```

## Producción

La aplicación puede ejecutarse con Docker o de forma local con la base de datos en PostgreSQL.

## Secciones principales

- Landing pública editable desde panel
- Gestión de productos y categorías
- Gestión de clientes y envíos
- Configuración del sitio y contenido
- Páginas legales y metadatos SEO
