# Contributing to DLA Viajes y Envios

Gracias por colaborar con este proyecto.

## Requisitos

- Node.js 18 o superior
- `pnpm` o `npm`
- Git

## Configuración rápida

```bash
pnpm install
pnpm dev
```

## Flujo recomendado

1. Crea una rama nueva para tu cambio.
2. Mantén los cambios enfocados y pequeños.
3. Verifica build, lint y pruebas antes de enviar.
4. Documenta cualquier cambio funcional relevante.

## Convenciones

- `feature/...` para nuevas funciones
- `fix/...` para correcciones
- `docs/...` para documentación
- `refactor/...` para refactors

## Comunidad

Antes de contribuir, revisa el [Code of Conduct](CODE_OF_CONDUCT.md).
